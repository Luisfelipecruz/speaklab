# SpeakLab API image.
#
# Invariant I5: NO torch and NO model weights in this image. Every model lives in asr,
# tts or pron. api/tests/test_health.py asserts it rather than trusting this comment —
# a transitive dependency that quietly pulls torch would add ~2 GB to the image that
# has to start fastest.

fastapi==0.115.8
uvicorn[standard]==0.34.0
python-multipart==0.0.20

# ── Database ────────────────────────────────────────────────────────────────
# asyncpg is the request-path driver. psycopg2-binary is here for Alembic (m2), which
# runs migrations synchronously — `postgresql+asyncpg://` is not a URL psycopg2 can
# parse, and config.py exposes SYNC_DATABASE_URL for exactly this.
sqlalchemy[asyncio]==2.0.38
asyncpg==0.30.0
psycopg2-binary==2.9.10
alembic==1.14.1

# ── Clients ─────────────────────────────────────────────────────────────────
# One async HTTP client for all four outbound callers: asr, tts, pron and Ollama. It is
# also the test client, so it was going to be here regardless.
httpx==0.28.1

# ── Auth (m3) ───────────────────────────────────────────────────────────────
#
# Argon2id, and argon2-cffi rather than passlib. m1 shipped `passlib[bcrypt]` here with
# a comment arguing bcrypt was good enough; PRD FR-1 says passwords are stored
# Argon2-hashed, and the PRD is the authority over a convenience call made in a
# requirements file. That settled the hash. Dropping passlib as well is a second
# decision with its own reason: passlib 1.7.4 was released in 2020 and is unmaintained,
# its bcrypt backend raises on bcrypt >= 4.1, and a wrapper whose value is switching
# between schemes buys nothing when there is exactly one scheme and no legacy hashes to
# migrate. argon2-cffi gives hash/verify/check_needs_rehash directly. If a second scheme
# is ever needed at once — importing users from an existing system — that is what
# passlib's CryptContext is actually for, and that is when to reconsider.
#
# It installs from a wheel on linux/amd64 and linux/arm64, so no compiler is added to
# the image. Verified on 2026-08-30 in this image: hashes carry the `$argon2id$` prefix
# at the library's default parameters (t=3, m=64 MiB, p=4).
argon2-cffi==25.1.0
pyjwt==2.10.1

# Pydantic's EmailStr, which is a FastAPI extra rather than a direct import. Hand-rolling
# an email regex is a well-known way to reject valid addresses, and the alternative of
# not validating at all makes the unique constraint on `users.email` the only thing
# standing between the table and two rows for the same person typed differently.
email-validator==2.3.0

# ── Tests and lint ──────────────────────────────────────────────────────────
pytest==8.3.4
pytest-asyncio==0.25.3
ruff==0.9.6
black==25.1.0
